# Earth-observation toolkit

## Stack

- `pystac-client`: Client for searching and accessing SpatioTemporal Asset Catalogs (STAC)
- `pyproj`: Interface for cartographic projections and coordinate transformations
- `earthengine-api`: Client library for accessing Google Earth Engine
- `geemap`: Interactive mapping with Google Earth Engine in Jupyter notebooks
- `odc-stac`: Tool for loading SpatioTemporal Asset Catalogs into Open Data Cube / xarray datasets
- `planetary-computer`: Library and utilities for accessing Microsoft Planetary Computer data and APIs
- `rasterio`: Interface to GDAL for reading and writing geospatial raster data
- `rioxarray`: Geospatial extension for xarray powered by rasterio
- `ipyleaflet`: Interactive Leaflet mapping widgets for Jupyter notebooks
- `ipywidgets`: Interactive HTML control widgets for Jupyter notebooks
- `pandas`: Data structures and analysis tools for tabular data
- `torch`: Deep learning and tensor computation framework
- `numpy`: Numerical computing and multi-dimensional arrays
